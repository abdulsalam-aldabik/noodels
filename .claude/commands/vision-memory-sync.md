# /vision-memory-sync

Use this command when starting or ending a session with claude-mem.

## Start-of-session

1. Query memory for project history and known failure patterns.
2. Record useful memory findings in logs/agent-work-log.md.

## End-of-session

1. Persist key lessons (what worked, what failed, why).
2. Keep memory entries short and reusable.
3. Update docs/context/copilot-continuation-handoff.md if handoff is needed.

## Rule

Do not store noise. Store only reusable project truths.
