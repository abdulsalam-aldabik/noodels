# /vision-plan-opus

Use this command to force a planning-only pass (no implementation edits).

## Expected model

Opus preferred for architecture/tradeoff reasoning.

## Output required

1. Problem diagnosis summary.
2. 2-3 architecture options with pros/cons.
3. Chosen architecture with rationale.
4. Phased milestone plan.
5. Acceptance criteria per phase.
6. Risk register + mitigations.

## Guardrail

No file edits except planning docs and log updates.
